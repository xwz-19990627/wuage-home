# wuage-home · 路线规划

> 已确认的方向见 [DECISIONS.md](DECISIONS.md)。随讨论更新，模块互相独立，统一由智能体内核调度。

## MVP 候选模块（讨论中）

| 模块 | 核心玩法 | 数据 | 交互 | 备注 |
| --- | --- | --- | --- | --- |
| A. 一句话记账 + 家庭周报 | 说一句记一笔，LLM 结构化；每周生成"人话"财报 | SQLite | Web | 建议第一个做，链路最短 |
| B. 家庭知识问答（RAG） | 保修卡/合同/缴费单/说明书/日志全入库，问"空调保修到几时" | 文件+向量库 | Web | 最有"智能体的家"的感觉 |
| C. 到期守望者 | 从账单/邮件/截图抽到期日，提前提醒 | SQLite | Web/邮件 | LLM 负责抽取 |
| D. 每日简报 | RSS 聚合 → LLM 去重过滤 → 每日 3-5 条 | 文件 | 邮件/Web | 配合新闻推送想法 |
| E. 睡前故事 / 回忆检索 | 基于真实家庭事件生成定制故事；日志反向检索"去年端午去哪了" | 日志库 | Web | 最有温度 |
| F. 票据/相册管家 | 拍照直接入账、相册自动整理加注 | 文件+视觉模型 | Web | 需要视觉模型，可后置 |

## 已定（详见 DECISIONS.md）

- [x] 运行环境：本机，可迁移（数据/配置外置，`WUAGE_DATA`）
- [x] 交互 MVP：本机 Web；后续 Web/App/微信/QQ 走适配器
- [x] 存储 MVP：SQLite + 文件，固定位置
- [ ] 第一个模块：待定（上表 A–F 任选，或另提）

## 技术栈草案（MVP）

- Python 3.11+ / FastAPI（Web + API）
- SQLite（Python 内置 sqlite3 或 SQLAlchemy）
- DeepSeek API（OpenAI 兼容，V4 Flash）做 LLM 调用
- 单页前端（原生 JS / 轻量框架），不引入构建链
- 定时：APScheduler（简报、提醒、周报）
