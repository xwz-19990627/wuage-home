# wuage-home · 版本规划（VERSION_PLAN）

> 节奏：**小版本滚动迭代**（做一点、记一点、发一点，见 docs/SPEC.md），
> MINOR 留给新模块正式引入。架构基线：DSH = 中枢，wuage 仓库 = 业务内核（docs/ARCHITECTURE.md）。
>
> ⚠️ **版本命名约定：没有「v2.0」**。记账与后续财务健康模块统一走 **v0.x 系列**：
> v0.1.x 记账起步 → **v0.2 系列（0.2.x 小版本滚动）** 财务健康（预算/资产/投资/理财/布局升级等）；
> v0.3+ 起为非财务模块（记忆/工具箱/入口）。
