# v0.1.0 归档（2026-08-21）

> 本文件是 v0.1.0 的完成归档（docs/SPEC.md 第 6 条）。摘要保留在 CHANGELOG.md。

## 一句话总结

wuage-home 记账 MVP 从零到可用：本地数据层 + DSH 技能卡 + 家庭管家预设 + 零依赖 Web 面板，全部打通并推送到 GitHub。

## 本版交付

- 数据层 scripts/ledger.py（CLI + 可复用数据函数，9 类校验，金额存分，WUAGE_DATA 可迁移）
- 技能卡 .dsh/skills/wuage-ledger/SKILL.md（一句话记账解析契约）
- 预设「家庭管家」+ 安装脚本（新会话选择器可选）
- Web 面板 scripts/web.py + web/index.html（127.0.0.1:8000）
- 规范体系：SPEC.md / CHANGELOG.md / VERSION_PLAN.md / specs 模板 / archive 机制

## 关键决策（详见 docs/DECISIONS.md、docs/VISION.md）

- 内核复用 DSH 壳子，wuage-home 只做记忆层 + 技能卡 + 主动剧本。
- 分类只做 9 项一级大类；原话进 note 作未来词表种子源。
- 数据固定位置 data/（WUAGE_DATA 可覆盖），迁移 = 拷目录。

## 遗留事项（下版本候选）

- tags / member 字段预留未启用（后续按设备区分家庭成员）。
- 微信/支付宝账单导入。
- 周报 LLM 人话叙述（现在只有聚合数据）。
- 主动提醒/定时（v0.5.x，任务看板 cron）。
