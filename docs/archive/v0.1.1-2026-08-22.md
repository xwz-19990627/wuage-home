# v0.1.1 归档（2026-08-22）

## 一句话总结

Web 面板从“能用”到“好用”：数据可视化（区间分析/类别占比/按日趋势）+ 完整行内编辑，并打包为可迁移 App。

## 本版交付

- 分析卡：本周/近7天/近30天/自定义；总支出/笔数/日均；按类别占比、按日趋势柱条。
- 行内编辑扩展为金额/日期/类别/备注全字段（PATCH）。
- 流水筛选合计行；页面 v0.1.1 标注。
- App 化：start-wuage.sh / stop-wuage.sh / selftest.sh / package.sh（dist 包）。

## 关键决策

- 本期只做可视化与编辑（用户拍板不做导入）；聚合在浏览器端完成，无后端改动。
- 打包不含 data/：数据目录始终单独迁移（可迁移原则）。

## 遗留事项

- 账单导入（CSV/微信/支付宝）、CSV 导出 → 后续版本。
- 周报 LLM 人话叙述 + 定时（v0.1.2 中枢主动第一步）。
- 多成员（member）、QQ bot 入口（v0.4+）。
