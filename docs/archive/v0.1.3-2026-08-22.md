# v0.1.3 归档（2026-08-22）

## 一句话总结

面板可用一句话智能记账（大模型自动归类），端口迁到不常见端口 17623，图表改为百分比 + 多色。

## 本版交付

- scripts/parse.py：OpenCode Go 网关直调（deepseek-v4-flash），契约与技能卡一致，失败重试。
- web.py /api/parse：解析即入库；无金额 422 提示。
- 前端：一句话输入主入口 + 手动录入折叠；柱图占总额百分比 + 每项不同颜色。
- 端口 8000→17623：systemd wuage-panel、网关 WUAGE_TARGET、start/selftest 脚本、文档全同步。

## 关键决策

- 解析凭据只用 **OPENCODE_GO_API_KEY**（用户指定），不触碰官方 DeepSeek key；
  网关 https://opencode.ai/zen/go（需浏览器 UA，否则被 Cloudflare 403）。
- 面板不绑定公网端口；远程仍走 https://47.99.118.10:8443/ledger/。
- DSH headless 模式本机依赖损坏（base bundle 缺 UI 皮肤包），暂不用于解析；
  架构预留：解析逻辑集中在 parse.py，后续可切换到中枢调用。
