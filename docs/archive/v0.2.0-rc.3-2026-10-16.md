### 2. 工程债（两个真隐患）

- **文件盒子数据写在仓库里**：默认目录曾是 `REPO_ROOT/data/files`，服务器实际写在 `/root/project/data/files`
  → 脱离数据根，备份与"拷走 /root/wuage"的迁移流程都会**静默漏数据**。
  已统一三级解析（`WUAGE_DATA` → `WUAGE_HOME/data` → `/root/wuage/data`），默认 `$WUAGE_DATA/files`；
  服务器数据已迁移（sha256 校验）+ 上传/下载/删除端到端验证。
- **每日备份只备份了 `ledger.db`**：理财/健康(含报告原件)/文件盒子全裸奔。
  `backup.sh` 重写为「sqlite 一致性快照 + 全量打包 + 清单比对 + 保留 7 份整包 + `--verify` 校验」，
  cron 日志移出仓库目录。

### 3. 理财收尾

- **复权口径**：回测可选口径（基金复权/累计/单位净值，ETF 前复权/后复权/不复权）。
  实测 163402 兴全趋势十年定投：**复权 +6.80% vs 单位净值 −28.41%（差 35.2 个百分点）**。
  没做"逐日分红再投资"的原因写在 `finance.py::_with_adj`（东财累计净值序列逐日抖动，
  逐日算分红会把噪声复利放大到 1e29）。
- **数据源回退**：基金 pingzhongdata → fundf10 历史净值；ETF 行情/日K 腾讯 → 东财。
- **AI 持仓体检**：读记账库 `fund_positions`/`fund_trades` 出人话解读
  （`ledger.py funds --analyze` / `POST /api/funds/analysis` / 面板理财页按钮），含规则化风险提示。

## 踩过的坑（留档）

1. 快速面板遮罩 `.pk-overlay`（fixed, z-index 999）会盖住作为**兄弟节点**的面板 → 面板需
   `position:fixed; z-index:1000`，外层容器固定全屏。
2. 弹窗初始 `style.display=""` 在 CSS 类写着 `display:none` 时**不会显示**（空串只移除内联声明）→ 必须显式 `block`。
3. 改账把 `exclude_id` 混进 PATCH body，而 `update_record` 对未知字段抛错 → 400；判重参数与入库参数要分开构造。
4. 时间流一行里分类名与备注挤成一行（两个 inline span）→ `.tl-main` 改 flex 纵向。
5. `ledger.py` 的 `__main__` 入口原本在文件中部，而 `cmd_funds` 定义在文件末尾 → CLI NameError；
   入口已挪到文件最末。
6. `pkill -f "web.py --port 17899"` 会**连自己所在的 ssh 命令一起杀掉**（模式匹配到自身命令行）→ 用 `[w]eb.py` 或 pgrep 取 pid。
7. 临时实例没带 `DSH_HOME`/`WUAGE_HOME` → 面板能开但一调模型就报"密钥未配置"（凭据链要环境变量）。
