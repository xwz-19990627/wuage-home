# v0.2.0-rc.3 · 记账布局升级（2026-10-16）

> 归档记录。spec：[docs/specs/wuage-ui-layout-v0.2.x.md](../specs/wuage-ui-layout-v0.2.x.md)（rc.3 部分）

## 一句话

记账工作区从"表格型账本"改成记账 App 的主流信息架构：**底部中央「＋」快速记账**、**概览三卡**、
**账单时间流**，并落地借来的低成本功能：**重复交易检测**、**分类图标/排序**、**滑动与轻点手势**。

## 交付内容

| 项 | 落地 |
| --- | --- |
| Tab 架构 | [概览][账单][＋][AI记账][理财]（拍板方案 A：财务并入概览） |
| 中央「＋」 | 凸起圆形按钮 → 快速记账面板（一句话 / 手动两页签，可互切） |
| 概览三卡 | 本月支出 / 收入 / 结余 + 日均 + 环比/同比 Pill + 分类占比环（预留预算进度环位） |
| 账单时间流 | 日期分组 + 每日收支小计 + 收支分色 + 分类图标；可切回表格视图 |
| 分类图标 | 种子 16 分类默认 emoji + 配色，老库自动回填；自定义分类前端退回哈希配色 |
| 分类排序 | `sort_order` 优先；分类管理 ↑↓ 换位；快速面板按使用次数排序（常用靠前） |
| 重复检测 | `GET /api/entries/check-dup`；同日期+同金额（近 30 天）命中即提示，可取消/继续 |
| 手势 | 账单行左滑露出删除/改、长按或轻点编辑；桌面按钮常驻 |

## 数据契约变化

- **无新表**。`categories.icon/color/sort_order` 三列历史已存在，本次只是补种子值 + 让它们真正生效。
- `/api/dashboard` 新增字段（向后兼容）：`month_income_cents`、`month_balance_cents`、
  `prev_income_cents`、`income_change_pct`、`income_count`、`expense_count`。
- 新接口：`GET /api/entries/check-dup`；`PATCH /api/categories/<id>` 支持
  `icon` / `color` / `sort_order` / `{"move":"up"|"down"}`。

## 踩过的坑（留档）

1. 快速面板的遮罩层 `.pk-overlay` 是 `position:fixed; z-index:999`，面板作为**兄弟节点**会被遮住接不到点击
   → 面板改 `position:fixed; z-index:1000`，外层 `#quick` 固定全屏。
2. 重复弹窗初始 `style.display=""` 在 CSS 类里写着 `display:none` 时**不会显示**（空串只是移除内联声明，
   类规则仍然生效）→ 必须显式 `display="block"`。
3. 改账把 `exclude_id` 混进了 PATCH body，而 `update_record` 会对未知字段抛
   `unknown field 'exclude_id'` → 400 保存失败；判重参数与入库参数要分开构造。
4. 时间流一行里分类名和备注原本挤成一行（两个 inline span）→ `.tl-main` 改 flex 纵向排列。
