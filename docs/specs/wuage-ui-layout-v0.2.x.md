# Spec：记账工作区 UI/布局升级 + 借鉴功能落地（v0.2.x）

> 复制自 docs/specs/_template.md。背景：用户调研薄荷记账（App Store id 1613127475，官方卖点：
> 截图自动记账/共同记账/投资记账/灵活预算/极速导入/多账本/周期记账）后确定：
> 截图记账不做；投资理财等财务功能在 0.2.x 小版本内实现；本 spec 聚焦「布局升级 + 低成本借鉴功能」一次落地。

## 目标

把记账工作区从"表格型账本"升级为记账类 App 主流的**信息架构与交互**，
同时落地一批零成本借鉴功能（重复检测、周期记账预留、AI 分析入口），
让蛙哥/残雪在手机上"顺手记、看得懂"。

## 范围

- 做（本 spec，一个 rc 交付）：
  1. **底部中央「+」记一笔**：Tab 栏重构为 [概览][账单][+][AI记账][财务]（家庭并入概览/账单？——家庭页保留为第 5 Tab 更强。改为：[概览][账单][+][AI记账][家庭]，财务并入概览？——见下方"信息架构"节拍板）。
  2. **概览页三卡**：本月支出 / 收入 / 结余 + 环比/同比 Pill + 分类占比环（预留预算进度环位）。
  3. **账单页时间流**：按日期分组 + 每日小计行 + 收入/支出分行 + 空态引导；桌面保留表格能力（同数据，另一视图）。
  4. **AI 记账入口强化**：支持超短句（"午餐20"）；概览/记账 Tab 顶部 AI 图标（智能分析对话占位 → 接入 DSH wuage-ledger 技能/周报）。
  5. **分类图标与排序**：categories 已有 icon/color 列 → 种子分类补默认图标（🍚🚌💊🛍️📚🎮🏠📶🧧❓）；记一笔面板常用分类靠前 + 可排序（CLI/页面）。
  6. **重复交易检测**：提交前按 日期+金额+分类 匹配近 30 天流水，命中提示"疑似重复"（可继续/取消）。
  7. **手势**：账单行进 左滑删除/长按编辑（保留桌面按钮）；Toast/确认沿用。
- 做（后续 0.2.x 小版本，各自立项）：
  8. 周期记账（recurring 规则表：房租/工资每月自动生成 → 记账或提醒）
  9. 预算（rc.4，含周期/结转余额选项）
  10. 账户体系（多账户/信用卡还款日，rc.5 前置）
  11. 极速导入（rc 后续：微信/支付宝/银行 CSV 自动识别，无需模板）
  12. 智能分析对话（一句话问"这月花哪了"，走 DSH 会话/技能）
- 不做（明确排除）：
  - 截图/照片自动记账（用户拍板不做）。
  - 多账本、云同步（家用单账本 + 私有服务器，不引入账号体系开销）。
  - 报销管理（家用弱需求，暂不做；如需仅加"可报销"标记）。

## 数据契约

- 本 spec 主体：**无新表**。用现有字段：
  - categories.icon / categories.color（已有列，本期补种子默认值并展示）。
- 后续（记录，不在本 spec 实现）：
  - accounts 扩多账户（表已存在，type 扩 credit）；recurring 新表（周期记账）；budgets 新表（rc.4 spec 细化）。

## 接口（API / 命令）

- 新增：GET /api/entries/check-dup?date=&amount_cents=&category= → {"dup": true, "matches": [...]}（近 30 天）。
- 变更：GET /api/categories 已带 icon/color → 前端直接用；CLI categories 增加 --icon/--color 与排序参数。
- 无其它新 API。

## 依赖 LLM 的点

- 超短句解析：现有 /api/parse 已支持口语（"午餐20"→2000 分），本期验证并补充示例 prompt 词条，不改架构。
- 智能分析对话：本期只放入口占位（右上 AI 图标 + 提示），正式分析走 DSH 会话（wuage-ledger 技能查询叙述），本 spec 不实现。

## 验收标准（可测试）

- [ ] Tab 栏含中央「+」，点开进入快速记账面板（AI 一句话 + 手动 tab 相同入口，两处可互切）。
- [ ] 概览页三卡（支出/收入/结余）+ 环比/同比 + 分类占比环，数据与 /api/dashboard 一致。
- [ ] 账单页时间流：日期分组 + 每日小计 + 收支徽标；空态引导；行内编辑/删除保留。
- [ ] 分类显示图标（种子默认），记一笔面板常用分类排序生效。
- [ ] 重复检测：同一日期金额分类凭证提交 → 提示"疑似重复"；不同金额不误报。
- [ ] 手机与桌面（窄/宽屏）均可用，浏览器刷新路由不变（#/ledger/…）。
- [ ] /tmp 独立库全量自测通过；正式库不直接验证（等用户导入真实数据）。
