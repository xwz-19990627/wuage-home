# Spec：Web 面板可视化与编辑（v0.1.1）

> 状态：已批准 2026-08-21（用户口头拍板：做可视化与编辑，**不做导入**）。

## 目标

把 Web 面板从“能用”打磨到“好用的家用账本视图”：数据可视化讲清钱花到哪，
行内编辑把改账变点按。纯前端增强，后端仅复用现有 API。

## 范围

- 做：类别占比视图（区间可切）、按日趋势视图（区间可切）、完整行内编辑
  （金额/日期/类别/备注）、筛选区间合计行、版本号标注。
- 不做（本期明确排除）：账单导入（CSV/微信/支付宝）、导出 CSV、多成员、定时任务。

## 数据契约

- 无 DSH 依赖；沿用 data/ledger.db 与 9 类清单（docs/DATA_MODEL.md），不改 schema。
- 聚合在浏览器端完成，数据源为现有 `GET /api/entries?from=&to=`（无 limit 时全量）。

## 接口（无新增后端接口）

- 前端新增：分析卡片（区间预设：本周/近7天/近30天/自定义）+ 两类图表（类别占比、按日趋势）。
- 编辑扩展：PATCH /api/entries/<id> 已支持 amount_cents/date/category/note，前端补齐控件即可。

## 依赖 LLM 的点

- 无（纯确定性代码）。本期不引入智能叙述，预留后续接入中枢会话。

## 验收标准（可测试）

- [ ] 分析卡：切换区间后类别占比与按日趋势随之更新；金额/笔数/日均正确。
- [ ] 任意一行可编辑金额/日期/类别/备注并保存（PATCH 成功且列表刷新）。
- [ ] 筛选流水时表头合计正确；清空筛选恢复。
- [ ] scripts/selftest.sh 全绿（health/categories/增改删回环）。
- [ ] 页面标注 v0.1.1。
